SALAT LERNEN – kompletter klickbarer Prototyp

Enthalten:
- Onboarding mit Mädchen/Junge
- Name + Sprache
- persönliches Dashboard
- 4 Gebetspositionen
- Schritt-für-Schritt-Lernmodus
- Browser-Sprachausgabe als Audio-Demo
- Mini-Quiz
- Fortschritt + Belohnungen
- Suren & Duas
- Gebetszeiten-Demo für Augsburg
- Einstellungen
- PWA manifest + Service Worker
- lokale Speicherung des Profils und Fortschritts

Hinweis:
Die Gebetszeiten sind aktuell Demo-Werte. Für eine produktive Version sollte eine geprüfte Gebetszeiten-Berechnung/API mit wählbarer Berechnungsmethode angeschlossen werden. Die religiösen Lerninhalte sollten vor Veröffentlichung fachlich geprüft werden.
